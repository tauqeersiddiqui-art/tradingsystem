Run `python login.py` once to refresh the daily-expiring Zerodha access token into `.env`; start the live bot with `PYTHONIOENCODING=utf-8 nohup python -u master_runner.py > /tmp/runner_live.log 2>&1 &`. Session handoff is documented in `SESSION_HANDOFF.md` (kill stale processes, verify token, start, monitor). Weekend model retraining is gated by a per-week file lock under `data/.retrain_lock_<year>_W<week>` created by the runner.
