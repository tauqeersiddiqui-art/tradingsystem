Run `scripts/setup_autostart.bat` as Administrator to register morning (9:10 AM) and afternoon (1:30 PM) weekly tasks under `TradingBot_Morning` / `TradingBot_Afternoon`. The supervisor defaults to a 15 s poll interval but accepts an optional argument (`python scripts/supervisor.py 30`). Historical data refresh requires `KITE_API_KEY` and `KITE_ACCESS_TOKEN` in `.env` and can be extended via `YEARS_BACK=3 python scripts/refresh_zerodha_data.py`. Afternoon restart sets `ALLOW_BROKER_POSITION_ON_START=1` to resume open positions from the morning session.
