Run `python login.py` once per day to refresh the Zerodha access token into `.env`; start the live bot with `PYTHONIOENCODING=utf-8 nohup python -u master_runner.py > /tmp/runner_live.log 2>&1 &`. Morning/afternoon sessions are launched via GitHub Actions (`trading_morning.yml`, `trading_afternoon.yml`) which write secrets into `.env`, run `login_headless.py`, then invoke `master_runner.py` with a timed window and cache `data/runtime_state.json` between jobs. Weekend model retraining is gated by a per-week file lock under `data/.retrain_lock_<year>_W<week>` created by the runner.
