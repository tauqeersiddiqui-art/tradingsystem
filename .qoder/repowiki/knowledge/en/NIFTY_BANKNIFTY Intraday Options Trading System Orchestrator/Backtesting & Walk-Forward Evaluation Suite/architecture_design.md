The module is organized as a set of independent entry-point scripts that share a common simulation kernel:

- `backtest_engine.py` defines the core classes: `OptionPriceSimulator` (premium-space PnL), `BacktestSignalEngine` (mirrors `LiveEngine.step()` using `ChampionPredictor`, `IntradayMLLearner`, `_safe_build_live_features`, `compute_entry_stops`, and `manage_position` from `engine.*`), and `BacktestEngine` which drives day-by-day simulation, position lifecycle, daily loss limits, cooldowns, and metrics export to CSV under `results/`.
- `scalp_backtest.py` and `scalp_wfo.py` implement an alternative momentum/scalp strategy with its own loop, comparing OLD vs NEW risk controls and performing randomized grid search over COOLDOWN/TRAIL/MOVE caps across walk-forward folds.
- `walkforward_oos.py` performs purged walk-forward OOS evaluation: trains LightGBM per fold on strictly pre-test data (with LOOKAHEAD embargo), simulates trades at multiple thresholds, and reports aggregate expectancy after full spread + brokerage costs; supports a diagnostic `STOP_MODE=matched` that exits on spot barrier hits instead of live stops.
- `forensic_oos.py` reuses the same simulation but records trade-level metadata (gross/net PnL, cost, exit reason, hour bucket, regime, confidence bucket) to diagnose why expectancy turns negative — direction accuracy, option friction, exit quality, overtrading, regime mismatch, CE/PE asymmetry.

Dependency direction is one-way: all scripts depend upward on `ml.*` (feature builder, predictor, indicators) and `engine.execution.risk_manager` / `engine.execution.profit_manager`; nothing in `engine/` or `ml/` depends back on `backtest/`. The shared `OptionPriceSimulator` and `_mins_to_close` are imported by the OOS scripts so premium-space accounting stays consistent across all runners.
