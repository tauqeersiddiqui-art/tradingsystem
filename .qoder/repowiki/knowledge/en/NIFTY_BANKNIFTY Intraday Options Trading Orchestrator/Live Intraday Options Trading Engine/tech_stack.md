Python trading engine built on top of Zerodha Kite Connect (`broker.kite.place_order`, `historical_data`, `orders`) for NFO options execution; ML stack uses a custom `ml.predictor_champion.ChampionPredictor` plus `ml.ml_intraday_learner.IntradayMLLearner` and optional `ml.day_classifier.DayClassifier`; pandas/numpy used for feature computation and resampling to 5m/15m/30m higher timeframes.
