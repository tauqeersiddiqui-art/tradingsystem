The module is a collection of independent entry-point scripts that share a common simulation kernel defined in `backtest_engine.py`. That file exposes `OptionPriceSimulator` (premium-space PnL from spot moves), `BacktestSignalEngine` (mirrors `LiveEngine.step()` by calling `ChampionPredictor`, `IntradayMLLearner`, `_safe_build_live_features`, `compute_entry_stops`, and `manage_position` from `engine.*`), and `BacktestEngine` which drives day-by-day simulation, position lifecycle, daily loss limits, cooldowns, and CSV export under `results/`. `scalp_backtest.py` and `scalp_wfo.py` implement an alternative momentum/scalp strategy loop with its own entry logic and compare OLD vs NEW risk controls, including randomized grid search over COOLDOWN/TRAIL/MOVE caps across walk-forward folds. `walkforward_oos.py` performs purged walk-forward OOS evaluation: it trains LightGBM per fold strictly on pre-test data with a LOOKAHEAD-bar embargo equal to the dataset label horizon, simulates trades at multiple thresholds, and reports aggregate expectancy after full spread + brokerage costs; it supports a diagnostic `STOP_MODE=matched` that exits on spot barrier hits instead of live stops. `forensic_oos.py` reuses the same simulation but records trade-level metadata (gross/net PnL, cost, exit reason, hour bucket, regime, confidence bucket) to diagnose why expectancy turns negative. Dependency direction is one-way: all scripts import upward into `ml.*` (feature builder, predictor, indicators) and `engine.execution.risk_manager` / `engine.execution.profit_manager`; nothing in `engine/` or `ml/` depends back on `backtest/`. The shared `OptionPriceSimulator` and `_mins_to_close` are imported by the OOS scripts so premium-space accounting stays consistent across all runners.
