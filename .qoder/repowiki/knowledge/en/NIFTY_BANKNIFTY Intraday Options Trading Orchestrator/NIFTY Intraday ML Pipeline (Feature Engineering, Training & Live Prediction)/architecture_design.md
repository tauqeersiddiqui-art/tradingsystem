The module is organized into four cooperating layers with a strict one-way dependency: `indicators.py` provides pure numpy vectorized indicators (ATR, Supertrend, ADX, VWAP) consumed by both offline and online feature builders; `feature_config.py` defines the canonical `FEATURE_COLUMNS` order (the single source of truth for train/live parity) and exposes `build_live_features` / `_safe_build_live_features` used by the live engine to compute the same 36 features per candle. `dataset_builder.py` consumes those indicators to produce `ml/models/training_dataset.csv` with first-touch barrier labels (`label_ce`, `label_pe`) over active Indian market sessions. `trainer.py` runs TimeSeriesSplit cross-validation on LightGBM and optional CatBoost models, applies Platt scaling via `predictor_champion.CalibratedLGBM`, selects thresholds by walk-forward expectancy, and only overwrites champion files after passing AUC ≥ 0.55, calibrated-prob std ≥ 0.05, and positive expectancy — otherwise saving as `*_candidate.pkl`. `predictor_champion.py` loads the deployed champions at runtime, optionally ensembles LGBM+CatBoost when both are present, validates feature presence, and returns calibrated probabilities plus threshold checks. `ml_intraday_learner.py` is a stateful singleton (`IntradayMLLearner`) that maintains per-day win/loss multipliers, adaptive thresholds, day-type detection (TREND/RANGE/VOLATILE/GAP), early-exit logic, and an optional Claude API review loop that can only reduce side multipliers. `day_classifier.py` is a separate mini-pipeline that classifies the whole day from the first 30 minutes using its own feature set and model. `feedback_trainer.py` appends live trade outcomes to `data/ml_feedback.csv` and can retrain models by merging weighted live feedback with historical data.
