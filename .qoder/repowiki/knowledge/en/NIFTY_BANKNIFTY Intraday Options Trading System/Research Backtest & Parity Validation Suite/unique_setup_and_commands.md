Run quick backtest generation: `python research/backtest/run_quick_backtest.py --start YYYY-MM-DD --end YYYY-MM-DD [--max-rows N]`, which auto-discovers a CSV under `data/` or `research/backtest/data/` and writes `research/backtest/results/trade_log.csv`. Tests require the historical file `data/historical/banknifty_1m_full.csv` or are skipped via `pytest.skip`. The runner inserts the repo root into `sys.path` before importing `engine.config.config` to establish the namespace package correctly.
