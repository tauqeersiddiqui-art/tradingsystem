The module is a flat documentation vault organized into four purpose-specific directories: `daily/` stores end-of-day summaries, `trades/` holds one file per day of individual trade records, `patterns/` catalogs auto-detected recurring failure modes, and `rules/` contains manually extracted trading rules derived from pattern analysis. Each subdirectory includes a README that acts as an index or template (e.g., the rules README defines a Condition/Action/Evidence template). The vault is initialized with a timestamped header in each README, indicating it is generated by an automation script rather than hand-edited.
