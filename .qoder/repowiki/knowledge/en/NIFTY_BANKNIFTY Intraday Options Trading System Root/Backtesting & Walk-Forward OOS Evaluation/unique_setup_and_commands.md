Each script is self-contained and run directly with `python backtest/<script>.py`. Inputs are controlled via environment variables: `FOLDS`, `OOS_START`, `BT_MAX_TRADES`, `BT_COOLDOWN`, `BT_SPREAD_PTS`, `ML_EDGE_MARGIN`, `FORENSIC_THR`, `MIN_TRADES_VERDICT`, and `BT_STOP_MODE` (live vs matched). Data paths are hard-coded to `data/historical/nifty_1m_full.csv` (scalp scripts) and `ml/models/training_dataset.csv` (OOS scripts); results are written to `backtest/results/`.
